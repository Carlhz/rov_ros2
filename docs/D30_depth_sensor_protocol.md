# D30 深温计通信协议

## 设备信息

- 型号：CERPTS05D30-485 型深温计
- 量程：5 MPa
- 供电：9-30V DC
- 通信接口：RS485
- 协议：MODBUS-RTU（主用）/ ASCII（兼容）

## 物理层

| 参数 | 值 |
|------|-----|
| 波特率 | 19200（默认，可配） |
| 数据位 | 8 |
| 校验位 | 无 |
| 停止位 | 1 |
| 可选波特率 | 9600, 14400, 19200, 38400, 43000, 57600, 76800, 115200 |
| 地址范围 | 0x01 ~ 0x63 (1 ~ 99)，默认 0x01 |

## MODBUS-RTU 协议

### MODBUS CRC16

- 多项式：0xA001
- 初始值：0xFFFF
- 参考：标准 MODBUS CRC16

### 读取压力和温度值（推荐）

**主机发送（8 字节）：**

| 字节 | 字段 | 值 | 说明 |
|------|------|-----|------|
| 0 | 地址 | 0x01 | 设备地址 1~99 |
| 1 | 功能码 | 0x03 | 读保持寄存器 |
| 2 | 寄存器地址高 | 0x89 |  |
| 3 | 寄存器地址低 | 0x39 |  |
| 4 | 寄存器数量高 | 0x00 |  |
| 5 | 寄存器数量低 | 0x04 | 读4个寄存器 |
| 6 | CRC低 | 计算 | MODBUS CRC16 |
| 7 | CRC高 | 计算 |  |

**完整命令示例（地址=1）：** `01 03 89 39 00 04 BE 58`

**从机响应（13 字节）：**

| 字节 | 字段 | 说明 |
|------|------|------|
| 0 | 地址 | 0x01 |
| 1 | 功能码 | 0x03 |
| 2 | 字节数 | 0x08（8字节数据） |
| 3 | 压力值 D3 | int32 最高字节 |
| 4 | 压力值 D2 |  |
| 5 | 压力值 D1 |  |
| 6 | 压力值 D0 | int32 最低字节 |
| 7 | 温度值 D3 | int32 最高字节 |
| 8 | 温度值 D2 |  |
| 9 | 温度值 D1 |  |
| 10 | 温度值 D0 | int32 最低字节 |
| 11 | CRC低 | MODBUS CRC16 |
| 12 | CRC高 |  |

**响应示例：** `01 03 08 00 01 94 CD FF FF CF DB A1 9C`

### 压力值解析

```
压力值 = int32（字节3-6，大端序）
单位：水深厘米（cm）
  → 水深(m) = 压力值 / 100
  → 压力(MPa) = 压力值 / 10000
  → 压力(0.0001MPa) = 压力值
```

示例：压力值 = 0x000194CD = 103629
- 水深 = 103629 cm = 1036.29 m
- 压力 = 10.3629 MPa

### 温度值解析

```
温度值 = int32（字节7-10，大端序），带符号
单位：0.001°C
  → 温度(°C) = 温度值 / 1000
```

示例：温度值 = 0xFFFFCFDB = -12325（有符号）
- 温度 = -12.325°C

### 读取设备地址

**发送（8 字节）：** `F8 03 80 30 00 01 B9 AC`

**响应：**
| 字节 | 字段 | 说明 |
|------|------|------|
| 0 | 固定 | 0xF8 |
| 1 | 功能码 | 0x03 |
| 2 | 未使用 | 0x00 |
| 3 | 字节数 | 0x02 |
| 4 | 未使用 | 0x00 |
| 5 | 地址 | 当前设备地址 1~99 |
| 6 | CRC低 |  |
| 7 | CRC高 |  |

### 设置设备地址

**发送（8 字节）：** `[当前地址] 93 80 30 00 01 [新地址] [CRC] [CRC]`

示例（从地址1改为地址2）：`01 93 80 30 00 01 02 6D D8`

**成功响应：** `01 93 00 02 01 01 E4 47`
**失败响应：** `01 93 00 02 02 02 A4 B6`

### 读取波特率

**发送（8 字节）：** `[地址] 03 81 31 00 01 [CRC] [CRC]`

### 设置波特率

**发送（8 字节）：** `[地址] 93 81 31 00 01 [波特率码] [CRC] [CRC]`

波特率码：01=9600, 02=14400, 03=19200, 04=38400, 05=43000, 06=57600, 07=76800, 08=115200

## ASCII 协议（兼容/旧版）

### 读取压力和温度值

**发送（6 字节）：**
| 字节 | 值 | 说明 |
|------|-----|------|
| 0 | 0x73 | 帧头 |
| 1 | 0x44 | 命令：读取压力和温度 |
| 2 | 地址十位 | ASCII，1~9 → '1'~'9' (0x31~0x39) |
| 3 | 地址个位 | ASCII，0~9 → '0'~'9' |
| 4 | 0x0D | CR |
| 5 | 0x0A | LF |

**响应（22 字节）：**
| 字节 | 字段 | 说明 |
|------|------|------|
| 0 | 0x73 | 帧头 |
| 1 | 0x44 | 命令回传 |
| 2 | 地址十位 | ASCII |
| 3 | 地址个位 | ASCII |
| 4 | 压力符号 | 0x30=正, 0x31=负 |
| 5-12 | 压力值 | 8位ASCII数字（千/百/十/个/0.1/0.01/0.001/0.0001） |
| 13 | 温度符号 | 0x30=正, 0x31=负 |
| 14-18 | 温度值 | 5位ASCII数字（十/个/0.1/0.01/0.001） |
| 19-21 | 校验和 | 3位ASCII数字，= 字节2-18数字值累加和的低3位 |

### 解析示例

```
响应: 73 44 30 31 30 30 30 30 30 35 32 33 30 30 30 32 31 38 30 32 35 0D
      S  D  0  1  +  0  0  0  0  0  5  2  3  +  0  0  2  1  8  0  2  5

地址 = 01
压力 = +00000523 (正数) = 0.0523 MPa
  → 水深 = 5.23 m (在淡水中，0.523 MPa ≈ 5.23 m)
温度 = +00218 (正数) = 21.8°C
校验 = 025 = 累加和(0+0+0+0+0+5+2+3+0+0+2+1+8) = 21  → 实际上校验和=025...
  (实际计算规则见代码中 ASCII 校验方式)
```

## 接口定义（RK3588 上）

- RS485 端口：ttyS3（通过 485 转换器）
- 波特率：19200
- 协议：MODBUS-RTU
- 设备地址：1
