# SF 系列超声波测深仪（高度计）通信协议

## 设备信息

- 型号：SF 系列超声波测深仪
- 用途：测量 ROV 到水底/目标物的距离（高度计模式）
- 通信接口：RS485 / TTL 串口
- 协议：自定义二进制帧协议
- 默认机号：1

## 物理层

| 参数 | 值 |
|------|-----|
| 波特率 | 9600 |
| 数据位 | 8 |
| 校验位 | 无 |
| 停止位 | 1 |
| 流控 | 无 |

## 数据帧格式

### 测量指令（主机 → 测深仪）

**长度：6 字节**

| 字节 | 值 | 说明 |
|------|-----|------|
| 0 | 0xAA | 帧头 1 |
| 1 | 0xA0 | 帧头 2 |
| 2 | DEV_ID | 机号（默认 1） |
| 3 | 0x00 | 保留 |
| 4 | 0x00 | 保留 |
| 5 | XOR_CHECK | 校验 = [0]^[1]^[2]^[3]^[4] |

**完整命令示例（机号=1）：** `AA A0 01 00 00 0B`

校验计算：`0xAA ^ 0xA0 ^ 0x01 ^ 0x00 ^ 0x00 = 0x0B`

### 测量响应（测深仪 → 主机）

**长度：17 字节**

| 字节 | 字段 | 说明 |
|------|------|------|
| 0 | 帧头 | 固定 0xAB |
| 1 | 帧头 | 固定 0xA0 |
| 2-3 | 状态 | 设备状态/噪声 |
| 4-5 | 最近目标距离 | uint16 大端序，单位 cm |
| 6-7 | 噪声等级 | 或其它状态 |
| 8-9 | 最强目标距离 | uint16 大端序，单位 cm |
| 10-11 | 回波数量/信号强度 |  |
| 12-13 | 保留 |  |
| 14-15 | 保留 |  |
| 16 | 校验/保留 |  |

### 距离解析

```
距离(cm) = uint16(byte[high], byte[low])
  → 距离(m) = 距离(cm) / 100.0
```

**注意：**
- 距离 < 20cm 的读数可能不可靠（盲区）
- 建议使用「最强目标距离」（字节 8-9）作为主测量值
- 在高度计模式下，该距离 = ROV 距水底/障碍物的高度

## 典型数据解读

```
发送: AA A0 01 00 00 0B
响应: AB A0 XX XX HH HL XX XX SS SL XX XX XX XX XX XX XX

其中：
  HH HL = 最近目标距离（字节4-5）
  SS SL = 最强目标距离（字节8-9）
  XX   = 其他数据
```

## 接口定义（RK3588 上）

- RS485 端口：ttyS5
- 波特率：9600
- 协议：自定义二进制（AA/A0 帧）
- 设备机号：1
- 轮询间隔：1Hz（可调，最大约 5Hz）

## 备注

- 测深仪上电后可能有残留数据，首次读取前需清空串口缓冲区
- 若连续多次无有效响应，检查供电和接线
- 水中使用时，超声波衰减较大，最大量程与水质有关
