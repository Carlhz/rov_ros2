The YLX camera IMU on Linux appears fundamentally different from Windows:
  - On Windows: IMU data auto-pushes on EP 0x82 without activation
  - On Linux: EP 0x87 never produces data regardless of:
    * uvcvideo bound/unbound
    * V4L2 streaming on/off
    * XU#4 control queries (all return PIPE error)
    * Direct libusb interrupt transfers

Possible root causes:
  1. Firmware detects OS and behaves differently (unlikely)
  2. IMU needs a vendor-specific USB control command that only
     the Windows driver sends during initialization
  3. EP 0x82 (Windows) vs EP 0x87 (Linux) are different endpoints
